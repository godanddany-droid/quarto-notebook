Group Project - Tic-Tac-Toe Endgame Dataset

Group Work

This database encodes the complete set of possible board configurations at the end of tic-tac-toe games, where “x” is assumed to have played first. The target concept is “win for x” (i.e., true when “x” has one of 8 possible ways to create a “three-in-a-row”).

Interestingly, this raw database gives a stripped-down decision tree algorithm (e.g., ID3) fits. However, the rule-based CN2 algorithm, the simple IB1 instance-based learning algorithm, and the CITRE feature-constructing decision tree algorithm perform well on it.

1 · Dataset Overview

Field Detail
Name Tic-Tac-Toe Endgame Database
Source UCI Machine Learning Repository
Landing page archive.ics.uci.edu/dataset/101
Scope All legal tic-tac-toe board configurations at end of game
Creator David W. Aha (1991)
Size 958 observations · 10 variables
Missing values None

Unit of observation: one row = one completed tic-tac-toe board. Each of the 9 squares is encoded as x, o, or b (blank). class = positive means x wins.

4 · Data Preparation

4.1 · Engineer features

ttt_feat <- ttt %>%
  mutate(
    x_count   = rowSums(across(tl:br, ~ . == "x")),
    o_count   = rowSums(across(tl:br, ~ . == "o")),
    b_count   = rowSums(across(tl:br, ~ . == "b")),
    center_x  = as.integer(mm == "x"),
    corners_x = rowSums(across(c(tl, tr, bl, br), ~ . == "x")),
    win       = as.integer(class == "positive")
  )

5 · Research Questions

  • Does controlling the center square favor x?
  • Does holding more corners increase win probability?
  • How does x count vs o count relate to outcome?
  • Which individual squares matter most for winning?

6.3 · Square Importance Heatmap

square_wins <- ttt %>%
  pivot_longer(cols = tl:br, names_to = "square", values_to = "piece") %>%
  filter(piece == "x") %>%
  group_by(square) %>%
  summarise(
    total    = n(),
    wins     = sum(class == "positive"),
    win_rate = wins / total,
    .groups  = "drop"
  ) %>%
  mutate(
    row = case_when(
      square %in% c("tl","tm","tr") ~ "Top",
      square %in% c("ml","mm","mr") ~ "Middle",
      TRUE ~ "Bottom"
    ),
    col = case_when(
      square %in% c("tl","ml","bl") ~ "Left",
      square %in% c("tm","mm","bm") ~ "Center",
      TRUE ~ "Right"
    ),
    row = factor(row, levels = c("Top","Middle","Bottom")),
    col = factor(col, levels = c("Left","Center","Right"))
  )

ggplot(square_wins, aes(x = col, y = fct_rev(row), fill = win_rate)) +
  geom_tile(color = "white", linewidth = 2) +
  geom_text(aes(label = scales::percent(win_rate, accuracy = 1)),
            size = 6, fontface = "bold") +
  scale_fill_gradient(low = "lightyellow", high = "steelblue",
                      labels = scales::percent) +
  labs(
    title    = "Win Rate per Board Square (when held by X)",
    subtitle = "Darker = higher win rate when x occupies that square",
    x = NULL, y = NULL, fill = "Win Rate"
  ) +
  theme_minimal() +
  theme(
    axis.text       = element_text(size = 12, face = "bold"),
    panel.grid      = element_blank(),
    legend.position = "right"
  )

The center and corner squares have the highest win rates — consistent with classic tic-tac-toe strategy.

6.4 · Animated Plot — Win Rate as X Accumulates Squares

anim_data <- ttt_feat %>%
  mutate(center_label = ifelse(center_x == 1,
                               "X holds center",
                               "X does NOT hold center")) %>%
  group_by(x_count, center_label) %>%
  summarise(
    win_rate = mean(win),
    n        = n(),
    .groups  = "drop"
  ) %>%
  filter(n >= 5)

anim <- ggplot(anim_data,
               aes(x = x_count, y = win_rate,
                   color = center_label, size = n)) +
  geom_point(alpha = 0.85) +
  geom_line(aes(group = center_label), linewidth = 1.2) +
  scale_y_continuous(labels = scales::percent, limits = c(0, 1)) +
  scale_color_manual(values = c("X holds center"         = "steelblue",
                                "X does NOT hold center" = "salmon")) +
  scale_size_continuous(range = c(4, 12), guide = "none") +
  labs(
    title    = "Win Rate as X Accumulates Squares",
    subtitle = "X count on board: {closest_state}",
    x        = "Number of X's on Board",
    y        = "Win Rate",
    color    = "Center Square"
  ) +
  theme_minimal() +
  theme(legend.position = "bottom") +
  transition_states(x_count, transition_length = 2, state_length = 1) +
  shadow_mark(alpha = 0.3, size = 3) +
  enter_fade() +
  exit_fade()

animate(anim, nframes = 60, fps = 8, width = 700, height = 450,
        units = "px", res = 96,
        renderer = gifski_renderer())

Center control dramatically increases win rate at every level of x count.

7 · Summary

Concept Finding
Class balance ~65% positive (x wins)
Most impactful square Center — highest win rate when held by x
Corner control More corners → higher win probability
Center + high x count Near-certain win for x
Blanks remaining More blanks = earlier board = less predictable outcome
